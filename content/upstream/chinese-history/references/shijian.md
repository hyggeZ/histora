# 事镜:兴衰五幕谱与事变时间线

以时统事,审局面处在哪一幕、下一幕通向哪里。分两部分:**五幕谱**用来定位,**时间线案例**用来推演。审时的要诀是司马光那句总纲:"夫事未有不生于微而成于著。圣人之虑远,故能谨其微而治之;众人之识近,故必待其著而后救之。"

## 一、兴衰五幕谱

组织(王朝、公司、团队)的兴衰在两书千馀年里反复重演,大致五幕。定幕不看规模看**行为特征**;同一动作在不同幕吉凶相反,所以先定幕、再谈策。

### 第一幕·起局
**幕征:** 资源劣势,信用为王;领头人亲力示范,规则极简,分利痛快。
**史证:** 刘邦入关"法三章耳"【史】;光武"推赤心置人腹中"收降卒【鉴】;魏文侯冒雨守猎约【鉴】;陈胜的反面——称王后杀故人,"由是无亲陈王者",六月而亡【史】。
**本幕正解:** 一切动作向"攒信用"对齐;叙事可以造(篝火狐鸣),信用不能透支。
**误配警示:** 此幕搞盛世排场、精细流程,是穿错幕的戏服。

### 第二幕·治世
**幕征:** 高速上升,言路畅通,任命被全组织当作风向标。
**史证:** 贞观君臣"兼听则明,偏信则暗";太宗"为官择人,不可造次。用一君子,则君子皆至;用一小人,则小人竞进矣";魏征偏在太平时说"唯喜陛下居安思危耳"【鉴】。
**本幕正解:** 把"被反对"修成制度管道(三镜);每个任命先算信号成本。
**误配警示:** 此幕最大风险是把上升归因于自己英明,为第三幕埋雷。

### 第三幕·盛极
**幕征:** 战无不胜,会上再无反对声,特例开始滑向惯例,恩宠最盛处埋着祸根。
**史证:** "日中则移,月满则亏;物盛则衰"【史·蔡泽语】;玄宗用李林甫,立仗马之喻一出,言路焊死【鉴】;霍氏之祸"萌于骖乘"【鉴】;智伯水灌晋阳时的得意与韩魏的变色【鉴】;苻坚倾百万南下,新附之众貌合神离,一败即"风声鹤唳"、举国解体【鉴】。
**本幕正解:** 在最高点做三件反本能的事:主动退(范蠡)、主动透明(郭子仪)、主动买"谔谔"之言(赵良所谓"千人之诺诺,不如一士之谔谔"【史】)。
**误配警示:** 此幕的扩张冲动最危险——吞下的每份"顺从"都可能在决战时反水(淝水)。

### 第四幕·中衰
**幕征:** 问题已"成于著":内耗公开化,人才按站队而非才德升黜,救火者受赏、防火者无人记得。
**史证:** 唐文宗叹"去河北贼易,去朝中朋党难"【鉴】;曲突徙薪之喻——建言曲突者无赏,焦头烂额者上座【鉴】;东汉谏臣"扬汤止沸,莫若支薪"【鉴】。
**本幕正解:** "支薪"不"扬汤":拆掉让站队有利可图的结构(重叠职权、模糊考核、单一晋升通道),裁判回到裁判席;重赏一次"防火者"以扭转激励。
**误配警示:** 此幕最诱人的错误是只换人不拆结构——换谁上来都会长成同样的派系。

### 第五幕·乱亡
**幕征:** 名分尽失("天下以智力相雄长"【鉴】),公开的荒谬无人指出(指鹿为马【史】),权臣的退路消失("司马昭之心,路人所知也"【鉴】),首事者一呼百应("王侯将相宁有种乎"【史】)。
**本幕正解:** 对个人而言此幕问的是去留与站位(参人镜:范蠡、张良、蒯通);对组织而言,能救的窗口在第三、四幕,到此幕多半只剩重开一局。
**判据提醒:** 分清第四幕与第五幕的界线——还有人敢说真话、裁判还有权威,就还在第四幕。

## 二、事变时间线案例

推演用。每案按时间列**决策点**,标出分岔处;对应用户的局时,先找到"他现在站在哪一个决策点上"。

### 晋阳之战(联盟围杀与一夜反转)【鉴·周纪】
1. 智宣子立瑶,智果谏"若果立瑶也,智宗必灭"——不听(继承错配,祸根)。
2. 智伯宴上辱韩康子、段规,谏者警告"主不备,难必至矣",答"难将由我"(树敌而不自知)。
3. 索地:韩谋士段规、魏谋士任章都劝给——"彼骄而轻敌,此惧而相亲"(受害者开始隐性结盟)。
4. 索赵地,赵襄子拒;智伯帅韩魏攻赵。襄子退往晋阳——选民心不选城坚:"民必和矣"(退守处的选择即胜负手)。
5. 水灌晋阳,"城不浸者三版";智伯得意"吾乃今知水可以亡人国也",韩魏当场变色(胜利前夜,联盟裂缝可见)。
6. 谋士絺疵点破"韩魏必反",智伯转告韩魏(最后一次警告被亲手废掉)。
7. 张孟谈夜出,"唇亡则齿寒"一句策反;决堤反灌,智氏族灭。
**机理:** 围杀联盟的每一家各怀其利;被围者最优解不是守,是拆。**分岔点在第5-6步:** 智伯若在船上读懂那两张变色的脸,尚可解。

### 鸿门前后(窗口的错过)【史·项羽本纪】
1. 项梁起事时尚知"先即制人,後则为人所制"(上一代人的决断)。
2. 鸿门宴:"项庄拔剑舞,其意常在沛公",项王不应(窗口开着,握刀者犹豫)。
3. 樊哙闯帐,刘邦借如厕遁走:"大行不顾细谨,大礼不辞小让。如今人方为刀俎,我为鱼肉,何辞为"(对面把窗口看得清清楚楚)。
4. 其后分封失衡、"衣绣夜行"东归、烹说者……至垓下"四面皆楚歌"。
**机理:** "当断不断,反受其乱"【史】;窗口比机会稀缺。**对读:** 韩信在蒯通面前的犹豫是同一分岔的镜像——"天与弗取,反受其咎;时至不行,反受其殃"【史】。

### 楚汉用人对账(组织能力的胜负)【史·高祖本纪/淮阴侯列传】
1. 萧何月下追韩信:"诸将易得耳,至如信者,国士无双"(识人+肯抬人)。
2. 陈平带着"盗其嫂、受诸将金"的简历被重用(用其长,不求全)。
3. 对面:范增在而不能用,韩信陈平皆楚之亡人。
4. 战后刘邦自总结"三不如"而"吾能用之"。
**机理:** 两个组织的人才流向,提前几年写出了胜负。**用法:** 复盘团队时先画"人才净流入/净流出"表——你是汉营还是楚营?

### 霍氏兴灭(恩宠即几微)【鉴·汉纪】
1. 霍光辅政、行废立,权倾朝野(功业顶点)。
2. 与宣帝同辇骖乘——史断"霍氏之祸萌于骖乘"(祸根种在最煊赫的一刻)。
3. 光死,家族不知收敛;告变者起。
4. 族诛。事后论功,救火者受封,当初谏霍氏收敛者无人记得——时人以曲突徙薪讽之。
**机理:** 祸生于微时形似恩宠;组织天然奖励救火、遗忘防火。**分岔点在第2步:** 权力形状可测化(交权、透明)则曲线改写——郭子仪是同题的满分答卷。

### 开元→天宝(言路的死亡曲线)【鉴·唐纪】
1. 开元:直臣在位,朝有诤言(第二幕)。
2. 李林甫入相:"口有蜜,腹有剑"(信息环境开始被改造)。
3. 立仗马之喻公开化:"一鸣辄斥去"——百官看清说话的下场(沉默成为共识)。
4. "野无遗贤"——人才入口焊死;玄宗从此活在定制的现实里。
5. 安史乱起,兵至而庙堂不知。
**机理:** 堵言路者不是听不到批评,是让批评从生成环节就不再发生。**判据:** 你的组织里,坏消息还能以原样上行吗?最近一个提坏消息的人,下场如何?

### 淝水(扩张的消化不良)【鉴·晋纪】
1. 苻坚统一北方,新并诸族"降而未附"(资产负债表虚胖)。
2. 倾国南下,号称百万(把顺从当成了认同)。
3. 寿阳城头"望八公山上草木,皆以为晋兵"(统帅心气已虚)。
4. 前锋小挫,全军自溃,"闻风声鹤唳,皆以为晋兵";前秦土崩,降附各族纷纷自立。
**机理:** 扩张吞下的每一份"顺从",都在决战时刻要求兑付。**用法:** 并购/扩张前先审"附"的成色:利益绑定了吗,还是只是暂时没反抗?
