# 使用说明

## 安装

把 `liangsimajing-0.1.0-arm64-release.apk` 复制到 64 位 Android 手机，允许当前文件管理器“安装未知应用”后安装。

当前构建面向个人侧载，使用本机稳定的 Android 调试证书签名。后续升级必须继续使用同一证书；如改用正式发布证书，需要先卸载旧版本。

## 首次配置

1. 打开应用，在首次配置页输入 API Base URL、模型名称和 API Key。
2. OpenAI 默认 Base URL 为 `https://api.openai.com`。
3. 模型名称必须是该 Key 有权限调用的 Chat Completions 兼容模型。
4. Key 使用 Android Keystore 加密存储，不包含在 APK、史料库或日志中。

建议为本应用创建独立、低额度的 API Key，并在平台设置预算提醒。

## 使用

描述：

- 已经发生、可以确认的事实；
- 你希望实现的结果；
- 不能接受的代价；
- 是否有时间压力；
- 你对其他当事人动机的猜测。

应用会先在本地召回历史案例和原文，再把有限的核验材料发送给模型。展开“本地召回的历史镜鉴”可以查看实际送入模型的原文段落。

## 数据与网络

- 史料和案例检索可以完全在手机本地完成。
- 生成分析需要联网，并会把当前问题、候选案例和相关原文发送给所配置的模型服务。
- App 禁止明文 HTTP，只有本机回环地址可用于调试。
- App 禁止 Android 自动备份，避免安全配置随系统备份迁移。

## 局限

历史类比不是预测。应用会尽量区分史实、史家评论、编者解释和模型推断，但重要的人生、医疗、法律和投资决定仍需结合现实证据及专业意见。
